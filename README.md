## 📌 Visão Geral

O **`oficina`** é um sistema desenvolvido em **Laravel** focado na gestão e organização de oficinas mecânicas. O projeto permite realizar o controlo de clientes, veículos, ordens de serviço, agendamentos e peças/serviços de forma centralizada e intuitiva.

---

## 🛠️ Tecnologias

- **Backend:** [PHP 8.2+](https://www.php.net/) / [Laravel](https://laravel.com/)
- **Frontend / Assets Build:** [Vite](https://vitejs.dev/) / Blade Templates
- **Gerenciador de Dependências:** [Composer](https://getcomposer.org/) & [NPM](https://www.npmjs.com/)
- **Análise Estática & Qualidade:**
  - [PHPStan](https://phpstan.org/) (Análise estática de código)
  - [Laravel Pint](https://laravel.com/docs/pint) (Formatador de código PHP)
- **Testes:** [PHPUnit](https://phpunit.de/)

---

## ⚙️ Como Executar o Projeto

### Pré-requisitos
Antes de começar, certifique-se de ter instalado no seu ambiente:
- **PHP** (>= 8.2)
- **Composer**
- **Node.js** & **NPM**
- Banco de Dados (MySQL, PostgreSQL ou SQLite)
